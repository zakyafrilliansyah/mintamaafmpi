A LITTLE WORLD FOR DWI 💗

Isi:
- index.html: website lengkap, responsive, dengan animasi dan 3 mini-game.
- Musik romantis dibuat secara original menggunakan Web Audio API (tanpa file musik eksternal). Pengunjung perlu menekan tombol Musik: OFF terlebih dahulu karena browser memblokir autoplay.

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka index.html di browser untuk mencoba secara lokal.

CARA MEMBUAT LINK ONLINE (GRATIS) DENGAN GITHUB PAGES:
1. Masuk ke https://github.com dan buat akun / login.
2. Buat repository baru, misalnya: little-world-for-dwi
3. Upload index.html ke repository tersebut (pastikan berada di folder utama).
4. Buka Settings > Pages.
5. Pada Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu proses publikasi. GitHub akan memberikan alamat website berbentuk:
   https://USERNAME.github.io/little-world-for-dwi/

CATATAN:
- Website ini statis; tidak memerlukan XAMPP, database, atau server PHP.
- Agar bisa dibuka lewat internet, file harus diunggah ke layanan hosting seperti GitHub Pages atau Netlify.
- Musik dibuat dengan nada sintetis lembut dan berjalan setelah tombol musik ditekan.
- Ganti teks surat di index.html jika ingin menambahkan permintaan maaf yang lebih personal.
